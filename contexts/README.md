# Context Manifests

These files define the **minimum sufficient context** for each DayLoop phase.

Normal rule:

```text
AGENTS.md (standing contract)
+ STATE.md
+ current phase brief
+ current context manifest
+ LEARNED_CONCEPTS.md
+ only the source/tests named by the manifest
```

If more context is needed, expand one dependency at a time and state why. Update a manifest when the additional dependency becomes a permanent requirement for that phase.
